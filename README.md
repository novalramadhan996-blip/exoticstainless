# Exotic Stainless

Website company profile, katalog, layanan, proyek, galeri, dan portofolio PDF untuk **Exotic Stainless**, jasa fabrikasi stainless steel custom di Jabodetabek.

## Fitur

- Beranda dan company profile
- Produk stainless steel custom
- Layanan fabrikasi, railing, pagar, gerbang, dan pekerjaan custom
- Galeri dan portofolio proyek
- Download katalog produk dan portofolio proyek dalam PDF
- Tombol WhatsApp untuk konsultasi dan permintaan penawaran
- SEO metadata, Open Graph, Twitter Cards, Schema.org, dan canonical URL
- Responsive desktop, tablet, dan mobile

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- TanStack Router
- jsPDF

## Development

```sh
git clone https://github.com/novalramadhan996-blip/exoticstainless.git
cd exoticstainless
npm install
npm run dev
```
